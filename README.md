# Roblox Code Redemption System

This project implements a code redemption system in Roblox Studio. The system allows players to redeem codes for weapons and currency rewards. The system includes a client-side GUI for entering codes and a server-side script to handle the redemption logic, including usage limits and expiration times.

## Install

1. Download the project files.
2. Open your Roblox Studio project.
3. Place the `CodeRedemptionGUI.lua` script in the StarterGui service.
4. Place the `CodeRedemptionServer.lua` script in the ServerScriptService.

## Use

1. Customize the codes and rewards in the `CodeRedemptionServer.lua` script as needed.
2. Adjust the GUI layout and appearance in `CodeRedemptionGUI.lua` as desired.
3. Ensure that the `leaderstats` folder and `Currency` IntValue are properly set up for currency redemption.
4. Test the system thoroughly to ensure all features work as expected.
